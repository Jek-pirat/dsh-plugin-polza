# Автовыпуск по содержимому пакета

Спецификация находится в ../specs/2026-11-21-auto-publish-design.md.

- Сравнить два npm-архива по упакованным файлам, нормализуя только версию в package.json. Проверить смену версии, содержимого и прав исполнения.
- Расширить publish.yml проверками и последовательным выпуском из main. Для тега сохранить проверку версии. Восстанавливать GitHub Release по gitHead из npm.
- Проверить типы, тесты, сборку и решение о выпуске на настоящем npm-архиве. После включения проверить GitHub Actions и npm.
