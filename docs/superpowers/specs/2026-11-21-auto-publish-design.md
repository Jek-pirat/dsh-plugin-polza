# Автовыпуск npm-пакета Polza

После успешных проверок в main GitHub Actions собирает пакет для текущего коммита и сравнивает его распакованные файлы с последней стабильной версией в npm. Для сравнения поле version в обоих package.json приводится к одному значению. При сравнении учитываются имена файлов, содержимое и права на исполнение.

Если состав изменился, workflow повышает patch-версию, публикует пакет через действующую настройку npm Trusted Publishing и создаёт тег и GitHub Release для выпущенного исходного кода. Повторный запуск сверяет состояние npm и GitHub и завершает прерванный выпуск. Выпуски выполняются последовательно. Для ручного выбора minor или major сохраняется выпуск по тегу.

Вариант с выпуском после каждого MR проще, но создаёт версии даже при правках одних тестов. Выбрано сравнение готового пакета. Оно охватывает скомпилированный код, локализации, ресурсы, README и публикуемые метаданные. Изменение инструмента сборки приводит к выпуску, если изменился результат сборки.

Первая проверка после включения охватит уже принятый MR №10. Ожидаемый первый выпуск — 0.3.3 при условии, что последней версией остаётся 0.3.2.
