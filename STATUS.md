# Текущее состояние dsh-plugin-polza

Обновлено 16 ноября 2026, MSK.

## Выбор провайдера модели

- Исходная версия: `12fa59a` (`v0.2.2`). Ветка `codex/polza-model-provider`.
- После выбора модели Polza в ряду управления сразу за пикером появляется список «Провайдер».
- Список берётся из карточки выбранной модели в каталоге Polza. Ручной выбор сохраняется по модели в локальной конфигурации Harness и применяется через `provider.only`. «Авто» сбрасывает выбор.

## Проверки

- Windows, Node 24: `npm run typecheck`, `npm test` (16 тестов), `npm run build`.
- Тест реального PiAiAdapter против локальной SSE-заглушки подтвердил наличие `provider.only` при ручном выборе и отсутствие поля в режиме «Авто».
- Изолированный профиль DSH Web в Edge: положение справа от пикера на 1200 и 850 px, загрузка разных списков для Claude Sonnet и DeepSeek, выбор, переключение модели, перезагрузка страницы и возврат к «Авто».
- Платная генерация не запускалась. Подсказка расхода использует существующую приблизительную оценку по тарифу модели из каталога и может отличаться от тарифа выбранного провайдера.

## Публикация и продолжение

Кандидат собран локально. Следующий шаг для передачи изменений — открыть PR из `codex/polza-model-provider`.
