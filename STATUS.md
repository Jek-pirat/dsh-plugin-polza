# Текущее состояние dsh-plugin-polza

Обновлено 16 ноября 2026, MSK.

## Выбор провайдера модели

- Исходная версия: `12fa59a` (`v0.2.2`). Ветка `codex/polza-model-provider`.
- В меню пикера для моделей Polza пункт «Провайдер» расположен между «Моделью» и «Усилием». Список использует те же стили и клавиатурную навигацию, что и «Усилие».
- Список берётся из карточки выбранной модели в каталоге Polza. Выбранные провайдеры поднимаются вверх в порядке нажатия. Приоритет меняется стрелками и сохраняется для каждой модели. Каждая попытка передаёт одного провайдера в `provider.only` и отключает резервную маршрутизацию шлюза. Плагин переходит к следующему только при явном HTTP-отказе доступности или лимите конкретного провайдера до начала ответа. «Авто» снимает все отметки. Старые одиночные настройки читаются как список из одного провайдера.

## Проверки

- Windows, Node 24: `npm run typecheck`, `npm test` (18 тестов), `npm run build`.
- Тест реального PiAiAdapter против локальной SSE-заглушки подтвердил закрепление первого маршрута, последовательный переход после HTTP 503, отсутствие перехода при лимите аккаунта и отсутствие поля `provider` в режиме «Авто».
- Изолированный Harness 0.2.2-rc.1 в Edge: порядок строк, совпадение стилей с «Усилием», навигация по Escape, списки Claude Sonnet и DeepSeek, выбор по порядку, перестановка стрелками в обе стороны, снятие галочки с возвратом строки на прежнее место, сохранение после перезагрузки и «Авто».
- Изолированный Harness с живой Polza 16 ноября 2026: при старом теле в прогретой сессии после перестановки на Cloudflare шлюз выбрал DeepSeek (`gen_2233550168977444865`); после закрепления первого маршрута та же сессия получила Cloudflare (`gen_2233550881591398401`). Основные вызовы содержали 33 описания инструментов; вывод ограничили 32 токенами на тестовом прокси. Расход за воспроизведение и проверку 0,30336905 ₽. Переход при отказе проверен локальной заглушкой.
- Подсказка расхода использует существующую приблизительную оценку по тарифу модели из каталога и может отличаться от тарифа выбранного провайдера.

## Совместимость и продолжение

Встроенный пикер Harness 0.2.2-rc.1 не предоставляет слот между моделью и усилием. Поэтому плагин занимает слот пикера компонентом на основе штатной реализации под MIT и использует общий каталог и операции выбора Harness. Сторонние расширения штатного слота подписи модели в этом компоненте не отображаются.

Изменения находятся в [PR #5](https://github.com/polza-ai/dsh-plugin-polza/pull/5) из `codex/polza-model-provider`.
