# Текущее состояние dsh-plugin-polza

Обновлено 16 ноября 2026, MSK.

## Выбор провайдера модели

- Исходная версия: `12fa59a` (`v0.2.2`). Ветка `codex/polza-model-provider`.
- В меню пикера для моделей Polza пункт «Провайдер» расположен между «Моделью» и «Усилием». Список использует те же стили и клавиатурную навигацию, что и «Усилие».
- Список берётся из карточки выбранной модели в каталоге Polza. Выбранные провайдеры поднимаются вверх в порядке нажатия. Приоритет меняется стрелками и сохраняется для каждой модели. Запрос передаёт `provider.order` и `provider.only`. «Авто» снимает все отметки. Старые одиночные настройки читаются как список из одного провайдера.

## Проверки

- Windows, Node 24: `npm run typecheck`, `npm test` (17 тестов), `npm run build`.
- Тест реального PiAiAdapter против локальной SSE-заглушки подтвердил порядок в `provider.order`, ограничение в `provider.only` и отсутствие поля `provider` в режиме «Авто».
- Изолированный Harness 0.2.2-rc.1 в Edge: порядок строк, совпадение стилей с «Усилием», навигация по Escape, списки Claude Sonnet и DeepSeek, выбор по порядку, перестановка стрелками в обе стороны, снятие галочки с возвратом строки на прежнее место, сохранение после перезагрузки и «Авто».
- Платная генерация не запускалась. Подсказка расхода использует существующую приблизительную оценку по тарифу модели из каталога и может отличаться от тарифа выбранного провайдера.

## Совместимость и продолжение

Встроенный пикер Harness 0.2.2-rc.1 не предоставляет слот между моделью и усилием. Поэтому плагин занимает слот пикера компонентом на основе штатной реализации под MIT и использует общий каталог и операции выбора Harness. Сторонние расширения штатного слота подписи модели в этом компоненте не отображаются.

Кандидат собран локально. Следующий шаг для передачи изменений — открыть PR из `codex/polza-model-provider`.
